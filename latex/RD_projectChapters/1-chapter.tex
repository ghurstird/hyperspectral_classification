\chapter{INTRODUCTION}
With the ability to capture electromagnetic signals across many narrow spectral bands, Hyperspectral imaging (HSI) reflects electromagnetic signatures across hundreds of spectral bands, revealing properties of the physical and chemical structures of the surface of the earth. Precise details at this level are not possible with conventional RGB imagery. HSI's capability to capture detailed spectral information make it highly useful in many fields including agriculture, environmental monitoring and defense. However, the advanced spectral information comes with the fundamental computational burden of the curse of dimensionality. When considering the scarcity of expertly annotated pixel samples, the cost of training machine learning and deep learning models increases significantly along with the model’s generalizability.

The gap in the performance of supervised versus semi-supervised deep learning (CNN, ViT, Self-Training) architectures due to high dimensionality and the scarcity of labeled data is the main focus of this research work. Two primary things set this work apart. One, a curriculum learning approach is used to the training of these models in a bid to stabilize optimization. Two, a multi-threaded GUI was created to the point where users can load their own data, get predictions, and do all this without needing to code or even touch the command line.

The remaining chapters of this report review and analyze our work in these areas. Chapter 2 focuses on analyzing the state of the art research. Design and methodology of the entire system including data processing and architecture are discussed in Chapter 3. Chapter 4 provides a set of results based on quantitative comparative experiments and Chapter 5 provides analysis of these results and proposes ideas and recommendations for future enhancements.

\section{Purpose}
The primary aim of this project is to describe, in detail, the performance disparity between supervised and semi-supervised learning as applied to the classification of high-dimensional hyperspectral data. The aim of this project can be broken into the following sub-aims:
\begin{itemize}
    \item To evaluate the performance of supervised and semi-supervised models on the standard hyperspectral datasets: Indian Pines, Pavia University, and Salinas.
    \item To evaluate the impact of Gaussian filtering and PCA on the classification of hyperspectral data.
    \item To introduce Curriculum Learning in training to each model to improve training stability and convergence.
    \item To carry out a balanced and fair assessment of each model.
    \item To develop a Python multithreaded GUI, allowing end users to use the models to classify data in real time and with no need to access the code.
\end{itemize}

\section{Preliminary Investigation}
There is an observable shift in pattern from using traditional machine learning models towards using models built on deep learning architectures in the literature on hyperspectral image classification. Current models face problems when dealing with big data since most are trained using a lot of labeled data. Constructing labeled data for hyperspectral images is an expensive and time-consuming endeavor due to the need for an expert in the field to assist with the data labeling.

This project aims to fill important gaps in the literature. While most models translate well to theory, they end up being just a concept, since most of them are scripts that require technical expertise to use. The application, based on the experimental code, uses a that gives users the ability to input their own datasets and receive results in near real time.
